# 本で床は抜けるのか・AI編（仮）— デジタルツイン計画

## これは何か

30年以上のジャーナリスト活動で積み重ねてきたテキスト・写真・動画・書籍PDFを整理・統合し、自分自身の「知の分身（デジタルツイン）」をローカルAIとして構築するプロジェクトです。

書籍『本で床は抜けるのか』（中公文庫）の続編にあたる企画「本で床は抜けるのか・AI編（仮）」の一部として、構築の過程をこのリポジトリに記録していきます。

## 目指すゴール

- 一次資料（取材メモ・日記・写真・動画）を検索可能な形に整理する
- ローカル環境でRAG（検索拡張生成）の仕組みを構築し、自分の言葉・論理で応答するAIをつくる
- 将来的には、同じ仕組みを他の人が自分の記録を遺すために使える形で公開し、終活支援サービスへつなげる

## 現在の状況（2026年8月時点）

- **ハードウェア**: RTX 5080 / RAM 64GB のデスクトップPCを構築（半年越しの不具合対応の顛末は `devlog/` 参照）
- **ソフトウェア**: AnythingLLM + Ollama（Mistral）で、直近データの長期記憶実験を開始
- **課題**: 検索結果の精度が低い問題に対応中。あわせて、日記データを日付単位に自動分割するパーサーの開発に着手予定

## データについて

このリポジトリにはコード・設計ドキュメント・進捗記録のみを置きます。日記・取材メモなどの個人データは一切含みません（`.gitignore` で除外しています）。

## 進捗記録

日々の作業ログは [`devlog/`](./devlog) に日付ごとに記録しています。何に詰まり、何を解決したかを、成果物より先に残していく方針です。

## 関わり方

現在は個人開発の初期段階です。技術的な課題は今後 Issues にまとめていきます。興味を持っていただけたら、Star・Watch・コメントなど歓迎します。特に以下の分野に関心がある方の知見を歓迎します。

- ローカルLLM / RAGアーキテクチャ
- OCR・音声文字起こしの自動化パイプライン
- 個人データのプライバシー設計
